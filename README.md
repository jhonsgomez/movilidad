# Proyecto Movilidad

Este es un proyecto de ejemplo utilizando el framework Laravel. Laravel es un framework PHP moderno y potente que facilita el desarrollo de aplicaciones web con una sintaxis elegante.

## Requisitos Previos

- **PHP >= 8.1**: Laravel requiere al menos PHP 8.1.
- **Composer**: Para gestionar las dependencias de PHP.
- **Servidor Web**: Apache, Nginx o el servidor embebido de PHP.
- **Base de Datos**: MySQL, PostgreSQL, SQLite o SQL Server.
